# 本地 Markdown 文档网页

## 启动

双击项目根目录中的 `启动文档网页.cmd`，然后在浏览器打开：

`http://localhost:3000/`

网页会在每次启动时自动读取并同步 `server` 目录中的 Markdown 文件和图片。新增 `.md` 文件后，重新启动网页即可在左侧文档库中看到。

## 使用

- 左侧选择或搜索 Markdown 文档。
- 右侧目录可以快速跳转到正文中的章节。
- 点击右上角“导出 DOCX”，网页会按当前 Markdown 内容生成 Word 文档并保存到浏览器下载目录。
- 导出的 DOCX 包含标题层级、正文、列表、表格、代码块和可读取的本地图片。

## 手动运行

如果需要在终端运行，请进入 `web` 目录后执行：

```powershell
npm install
npm run dev
```

Node.js 版本需为 22.13 或更高版本。
