# 本地文档网页

## 启动

双击项目根目录中的 `启动文档网页.cmd`，然后在浏览器打开：

`http://localhost:3000/`

网页会在每次启动时自动读取并同步 `documents` 目录（包括多级子目录）中的 Markdown、PDF、DOCX 文件和图片。新增 `.md` 或 `.pdf` 文件后，重新启动网页即可在左侧文档库中按目录看到。

## 使用

- 左侧选择或搜索 Markdown 文档。
- PDF 文档会直接在网页中预览，也可以在新窗口打开。
- 如果 PDF 旁存在同名 DOCX，可以点击右上角下载原始 DOCX。
- 右侧目录可以快速跳转到正文中的章节。
- 点击右上角“导出 DOCX”，网页会按当前 Markdown 内容生成 Word 文档并保存到浏览器下载目录。
- 点击“下载 Markdown”可保存原始 `.md` 文件；如果文档引用了本地图片，网页会生成 ZIP，并按原目录结构一并打包 Markdown 与所引用的图片。
- 点击“导出 PDF”会打开系统打印窗口，选择“另存为 PDF”即可按 A4 版式保存当前 Markdown 文档。
- 导出的 DOCX 包含标题层级、正文、列表、表格、代码块和可读取的本地图片。

## 手动运行

如果需要在终端运行，请进入 `web` 目录后执行：

```powershell
npm install
npm run dev
```

Node.js 版本需为 22.13 或更高版本。
